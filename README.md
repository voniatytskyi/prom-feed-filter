# Фільтр фідів EasyDrop: без уцінки, браку та нюансів

## Що вирізається
- товари, у назві яких є «уцінка / уценка / брак / дефект / нюанс / некондиція / пошкоджено»;
- товари, у яких це слово стоїть у параметрі, наприклад «Розмір: 41 уцінка» або «40 (нюанс)»;
- усі товари з категорій постачальника, що називаються «Уцінка…» або «Брак».

Що лишається:
- «без потертості», «без дефектів» не вважаються браком;
- категорії SALE та «Розпродаж» скрипт не чіпає.

Перевірка на фідах станом на 18.11.2026:

| Фід | Товарів | Вирізано |
| --- | --- | --- |
| easydrop1 | 28 341 | 325 |
| easydrop2 | 18 552 | 254 |
| easydrop3 | 21 388 | 517 |

## Запуск
Потрібен лише Python 3.8 або новіший, без додаткових бібліотек.

```
python filter_feeds.py
```

Результат з'явиться в папці `output/`:
- `easydrop1.xml`, `easydrop2.xml`, `easydrop3.xml` — очищені фіди;
- `removed_*.csv` — список вирізаних товарів із причиною (відкривається в Excel).

Скрипт має запобіжник. Якщо постачальник віддасть битий чи порожній файл або фільтр вирізав би понад 15% товарів, старий очищений файл не перезаписується. Так Prom не зніме товари з продажу через помилку.

## Як це працює на GitHub
- Workflow `.github/workflows/filter-feeds.yml` запускається щогодини о хх:17 за UTC.
- Посилання на фіди з ключами зберігаються в секреті репозиторію `FEEDS` (формат той самий, що в `feeds.txt`). Файл `feeds.txt` у репозиторій не потрапляє.
- Очищені фіди публікуються на GitHub Pages за адресою `https://<логін>.github.io/prom-feed-filter/easydrop1.xml`. Так само для easydrop2 і easydrop3.
- Ручний запуск: вкладка Actions → Filter supplier feeds → Run workflow.

## Як підключити до Prom
1. Дочекатися першого успішного запуску workflow.
2. Відкрити посилання на очищений фід у браузері й переконатися, що файл відкривається.
3. В імпорті Prom замінити посилання EasyDrop на посилання на очищений файл.
4. У налаштуваннях імпорту для товарів, яких немає у файлі, вибрати «немає в наявності» або «приховати». Тоді вже завантажені товари з уцінкою зникнуть із вітрини після першого імпорту.

## Список виключень (`exclude_rules.txt`)
Окремий файл для брендів, на які подавали скарги, ознак копій («в стилі», «копія», «1:1», Replica) і конкретних кодів товарів, які вилучив Prom. Щоб додати товар, допишіть рядок `code: 1234567`, де 1234567 — число в кінці коду. Щоб вимкнути правило, поставте `#` на початку рядка.

## Правила
Слова для пошуку задані на початку `filter_feeds.py` у рядках `BAD_WORDS` і `BAD_CATEGORY`. Щоб додати нове слово, допишіть його через `|`.
